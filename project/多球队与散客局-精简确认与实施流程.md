## 1. 一句话

一期只做周三联 + 界龙散客。界龙报名只点一次，进「待分队」；老板再分成 2～6 队，每队大约 7～9 人，人数可以不齐。分成 4、5 或 6 队时自动生成对战场次，不用再点界龙杯。两队的系统鸽子都可以删。

## 2. 球员实际怎么用（不看说明也能做）

**入队与顶栏（定稿）**

- 入队主路径：活动分享链接 → 打开详情 → 报名 → **自动加入该场所属球队**。无公开球队目录，无「新建球队」。
- 「我的球队」只列已加入的队；文案提示「请让管理员把活动分享给你」，不可点进选队目录。
- **未入队**：首页不展示下一场，只引导等分享链接；活动/数据/球员为空态。
- **一支球队**：顶栏只显示队名，不可切换（无 ▾）。
- **多支球队**：顶栏可切「全部 / 各队」，**记住上次筛选**；打开某场活动（分享/列表/首页）后自动切到该场球队。
- 首页大卡跟当前筛选；筛单队时，若另一队也有未开赛，大卡下一行提示，点进去切过去。
- 界龙活动统一进 `session` 页（含分享）；周三联进 `activity` 页。
- 球员页在「全部」下只读；改资料/授管理员须先切到具体队。

**加入球队**

- 周三联：加入时必选 jiong 路青少年（黄）或浦东老聚三（粉白）。报名仍按现在的分队 / 联合。
- 界龙：名册有常驻六组（塔子🕊 / 界龙⭐️ / 伤心🇮🇹 / 汤姆🐻 / 爱情🔥 / 散客⚽️）。第一次报名时**必选**名册组，界面默认勾「散客⚽️」，可改成别的；**本场仍一点进待分队**，由老板当场再分成 2～6 队（名册组 ≠ 当场队）。之后可在「我的」改名册组。

**报名（界龙）**

- 点一次「报名」就结束，结果是「已报名」，不选队伍。
- 人数达到老板设的本场上限（默认 40）后，再报名的人进后补。后补只有一条队列，有人退出正选就按顺序顶上。
- 球员自己不能挑队、不能改队。想换队找老板。

**报名之后怎么展示**

未分队时只有一块名单，名字排成 **2 列**（约 30～40 人时大约 15～20 行）。不用 1 列，也不用 3 列：3 列在手机上字小、难点。不出现空队窗口。

```text
已报名 32 人
张三   李四
王五   赵六
…
[ 分成若干队 ]          ← 只有老板看得到
```

老板分完以后，**队是一块一块的卡片**，和「名字排成 2 列」不是一回事。一行放两张队卡，多的往下排。3 队是两行（第二行一张），4 队是两行，6 队是三行。每张卡里只有 7～9 人，名字在卡内竖着排，不再用两列。空队不展示。

```text
[ 红 9 ]          [ 白 8 ]
  张三 …            李四 …

[ 黄 8 ]          [ 绿 7 ]
  …

未分队 1          后补 0
```

换队：按住一个人，拖到另一张队卡上松开。也可以点这个人，再点目标队的队名。3 队、4 队、6 队都是同一套动作，只是卡片行数不同。

**老板怎么分人**

1. 人来得差不多时，点「分成若干队」，选 **2～6 队**。6 队少用，但可以选。
2. 可选每队大概人数：7、8 或 9。系统按人头尽量分匀，允许 7 对 8、8 对 9。分不完的人留在「未分队」。
3. 分完后老板拖人换队、把未分队的人拖进某一队、改这一队的名字和球衣色。这些名字和颜色只属于这一场。
4. 还没有比分、也没有进球时，可以重新分队。有了之后，队伍锁定。

**对战场次**

- 不用点界龙杯。老板分成 **4、5 或 6 队**时，系统按预设自动生成对战场次。本期只做这三种。
- 2 队或 3 队不生成场次。进球、助攻、乌龙记在整场活动上。
- 4、5、6 队：每场记最终比分；进球、助攻、乌龙记在这一场上（进球者必填，助攻可空，乌龙不自动改比分）。积分榜排序：积分、净胜球、总进球、猜拳。比分和进球条数不强求相等。
- 出勤记在整场活动上。鸽子也记在整场活动上。系统自动记下的鸽子，两队的管理员都可以删掉。
- 还没有任何比分、也没有任何进球时，改成 2 队或 3 队会清掉场次图。已经有了就锁定队数。
- 周三联不生成场次、不记比分。进球、助攻、乌龙、出勤、鸽子都在整场活动上。系统鸽子同样可以删。

## 3. 规则（避免互相打架）

**分组**

- 周三联仍有常驻分组。改名、改色不改变谁属于哪一组。数据页按报名当时的组筛选。
- 界龙有常驻名册六组（我的 / 球员 / 数据可筛）；本场报名不按名册组入坑，进待分队后由老板当场分队。当场队名、颜色、人数只属于这一场。

**名额**

- 界龙：本场报名上限默认 40。未分队前，到顶进后补。分队后每队大约 7、8 或 9 人，老板可把人拖成 7 对 8、8 对 9。队数 2～6。
- 周三联后补、鸽子、开赛前取消是否记鸽子，保持现在的规则。界龙用同一套取消和鸽子规则（截止小时默认 4）。两队管理员都可以删除系统鸽子。

**谁能改什么**

- 你是两队主管理员（授权人）。在某一队里打开的管理员，只在那一队有效。
- 开赛前：主管理员和普通管理员都能改标题、时间、地点。开赛后这三项都不能改。活动时间必须带周几。
- 界龙换队只有老板操作。周三联开赛前，球员仍可把自己拖到未满的组。
- 还没有任何比分、也没有任何进球事件时，老板可以重新分队、调人。一旦有了，队伍锁定。
- 4、5、6 队的对阵用长文里已有的轮次表。还没有比分的场次可以改对阵和场地。2 队、3 队本期不排场次。
- 积分榜的进球、失球用**场次比分**相加。排序：积分、净胜球、总进球、猜拳。

**必须留下的现有能力**

- 后补：排队、有人退出自动顶上、候补通知、取消后补不记鸽子。
- 订阅消息：报名/后补时的候补通知、开赛前提醒（活动开始通知）。
- 球员卡：战术板、导出海报。
- 首页下一场天气。
- 周三联开赛前拖自己到未满组、管理员对调。界龙只由老板分人和改组。

## 4. 一期做什么

```text
Step 1  两队底座、周三联常驻分组、周几、你兼任两队主管理员
Step 2  界龙只报名不选队；老板分成 2～6 队（每队约 7～9 人，允许不齐）
Step 3  分成 4/5/6 队时自动生成场次图 + 场次比分 + 国际足联积分榜
Step 4  进球事件：开杯挂场次，不开杯和周三联挂活动；乌龙不改比分
Step 5  确认后补、订阅消息、战术板、天气仍可用
Step 6  单测 + 冒烟 + 文档对齐
```

不做：夺冠概率、新建第三支球队、球场排期、向散客池招人。

| 期 | 做什么 |
| --- | --- |
| 一期 | 上面全部 |
| 二期 | 通用建队模版 |
| 三期 | 向散客池补人 + 更多球场 |
| 四期 | 球场排期 |
| 以后 | 夺冠概率（能力分 8/9/10） |

## 5. 自检（写文档时已按此排除）

- 界龙报名不选队，未分队时只有一块名单。
- 队是老板当场分出来的，2～6 队，每队约 7～9 人，允许 7 对 8、8 对 9。
- 球员不能自己改界龙的队。分成 4、5、6 队自动有场次；2、3 队没有场次。有比分或进球后不能再改队数。
- 系统鸽子两队都可以删。
